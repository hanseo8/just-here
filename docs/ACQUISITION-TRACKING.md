# 유입 집계 개선 — 2026-11-18

## 집계 기준

- 관측 방문은 브라우저 탭의 방문 ID 기준이며, 사람 수·광고 클릭 수와 다릅니다.
- 30분 활동이 없거나 새로운 캠페인으로 진입하면 새 방문으로 집계합니다.
- 방문 → 추천 노출 → 가게 선택 → 지도·주문 열기를 순서대로 집계합니다. 지도 열기는 실제 방문이나 결제 완료가 아닙니다.
- 같은 방문의 반복 클릭은 단계별 1회만 집계합니다. 날짜는 한국 시간 기준입니다.
- 출처 라벨이 없으면 출처 미확인/직접으로 표시합니다. 과거 이벤트에는 출처를 소급 추정하지 않습니다.
- 미리보기와 로컬 웹 테스트는 제외합니다. 네이티브 앱의 localhost는 운영 환경일 수 있어 별도로 처리합니다.

## 관리자 화면

기존 인증이 필요한 /analytics에서 확인합니다. 관리자 토큰을 URL에 넣거나 브라우저 저장소에 저장하지 않습니다.
첫 추천 3개 안 선택률이 미선택률로 표시되던 오류도 수정했습니다.

## 검증과 한계

격리된 로컬 데이터로 중복 제거, 단계 순서, 캠페인 분리, 한국 날짜, 미리보기 제외, 인증·캐시·문자열 삽입 방어를 검사했습니다. 화면의 demo_threads 수치는 합성 테스트 데이터입니다.
스크립트 차단·통신 실패·탭 간 이동은 관측에 영향을 줍니다. 기존 최근 20,000개 이벤트 조회 한도가 유지되므로 대규모 운영에서는 별도 집계 저장소가 필요합니다. 지급 증빙이나 부정 참여 판정 자료로 사용하지 않습니다.

현재 로컬 개발·검증 상태이며 운영 배포와 새 앱 패키지 빌드는 하지 않았습니다.
