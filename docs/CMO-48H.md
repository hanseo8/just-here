# CMO · 소프트런치 48시간 작전

**목표:** 유료 광고 없이, 오늘부터 **실사용자 30명 · 매칭 20회 · 공유 5회**  
**지표:** https://www.justthis.co.kr/analytics  
**제품 URL:** https://justthis.co.kr

---

## 원칙 (CMO 룰)

1. **링크 + 영수증 캡처**만 뿌린다. 긴 설명 금지.
2. **“오늘 뭐 먹지”가 열린 자리**에만 넣는다. 스팸 금지.
3. 카톡 인앱에서 열면 위치가 막힐 수 있음 → 가능하면 **「인터넷으로 열기」** 한 줄 추가.
4. 매일 밤 `/analytics`에서 **오픈 → 세션 → 매칭 → 공유**만 본다.

## Day 0 (오늘, 지금) — 30분

### 체크리스트
- [ ] 본인 폰에서 1회: 위치 → 시작 → 매칭 → 영수증 캡처 저장
- [ ] 카톡 **가까운 지인 5명**에 아래 메시지 발송
- [ ] 회사/학교/친구 **단톡 1곳**에 짧은 버전 발송
- [ ] 인스타 스토리 1장 (영수증 + 링크 스티커)

### 카톡 DM (복붙)

```text
야 점심/저녁 고민할 때 이거 써봐
그냥여기 → https://justthis.co.kr

위치 허용하고 카드만 고르면 근처 맛집 바로 나옴
카톡으로 열면 위치 안 될 수 있어서, 메뉴에서 「인터넷으로 열기」 추천
```

### 단톡용 (더 짧게)

```text

https://justthis.co.kr

```

### 인스타 스토리 캡션

## Day 1 (내일) — 채널 확장

| 순서 | 채널 | 액션 | 예상 유입 |
|------|------|------|-----------|
| 1 | 카톡 오픈채팅 (지역/직장/맛집) | 질문형 1회 게시 | 중 |
| 2 | 회사 슬랙/잔디 `#random` | 링크 + 한 줄 | 중 |
| 3 | 인스타 피드 or 릴스 | 15초: 스와이프→영수증 | 중~높 |
| 4 | 당근 동네생활 (해당 지역만) | 유용한 글 톤, 도배 X | 낮~중 |

```text
근처에 “오늘 뭐 먹지” 빨리 정하는 웹 써보신 분 있어요?
저는 그냥여기 써봤는데 위치 찍고 카드만 고르면 끝이라 편하더라고요
https://justthis.co.kr
(광고 아니고 지인 소프트런치 피드백 받는 중이라 의견 환영합니다)
```

### 당근 동네생활 (지역명 바꿔서)

