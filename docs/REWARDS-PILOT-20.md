# 첫 영수증 파일럿: 승인된 규모

20개 계정, 계정당 승인 1건, 300P/건, 총 6,000P(계좌 교환 시 총 6,000원), 모집은 실제 개시일부터 2026년 10월 31일 23:59 한국시간까지이며 20건이 먼저 차면 조기 마감한다. 기존 7일 조건은 대체됐다. 보상과 지급은 현재 OFF이며 이 문서는 개시 승인이 아니다. 운영 비용은 지급 예산과 별개다.

## 적용할 환경 설정

- RECEIPT_REWARDS_MAX_CLAIMS=20
- RECEIPT_REWARDS_MAX_CLAIMS_PER_USER=1
- RECEIPT_REWARDS_END_AT=2026-11-01T00:00:00+09:00 (배타적 경계: 10월 31일 23:59분 전체 허용)
- RECEIPT_REWARDS_ALLOW_VOLATILE=off

실제 시작일은 검수 완료 후 결정하며 10월 1일로 소급하지 않는다. 접수 중과 승인 건수를 합산해 자리를 예약한다. 반려 건은 슬롯을 반환한다. 현재 상한은 기존 원장을 포함하므로 개시 전 관리자 현황에서 기존 pending/approved 건을 확인한다. 새 파일럿을 위해 원장을 삭제하지 않는다. 동일인 다중 계정 판별은 자동 보장하지 않으며 계좌·영수증 중복 등 관리자 검토가 필요하다.

## 검토와 지급

1. 추천에 연결된 실제 방문 결제인지, 매장·결제 시각·금액·승인번호·중복 여부를 확인한다. 긍정적인 리뷰를 승인 조건으로 삼지 않는다.
2. 승인하면 300P 적립. 모호한 영수증은 확인 후 처리하며 승인만으로 송금하지 않는다.
3. 계좌 지급 신청을 관리자 처리 중으로 전환하고 계좌 정보를 확인한다.
4. 관리자가 은행에서 300원을 직접 송금하고 실제 거래내역과 고유 거래 참조를 확인한 뒤 지급 완료로 기록한다. 자동 송금은 없다.
5. 송금이 불확실하면 재송금·반려하지 않는다. 거래내역을 먼저 확인한다. 반려로 포인트를 돌릴 때는 미송금을 확인한다.

네이버포인트 교환은 구현되지 않았다. 이 파일럿에서 지원하는 방식은 계좌 수동 지급이다. 네이버포인트 선택지를 안내하지 않는다.

## 개시 전 남은 확인

- 사용자 참여 문구·계좌 지급 동의·반려 안내에 동일한 범위와 조건을 표시한다.
- 운영 rewards DB 및 이미지 백업을 확보하고 격리 경로 복원을 확인한다. 로컬 테스트 통과만으로 운영 백업을 완료 처리하지 않는다.
- 실기기 영수증 업로드와 2FA 관리자 승인 화면 확인.
- 시작 시각·종료 시각을 확정하고 운영 20건 한도를 확인한 뒤 별도로 기능을 켠다.

마감은 신규 접수만 제한한다. 기존 접수 검토와 지급은 이어서 처리한다. 코드의 계정당 제한은 UID 기준이며 주민등록 등 본인 식별 시스템이 아니다.

2026-10-04 운영 읽기 전용 확인: /data의 rewards.sqlite3가 아직 없어 보상 백업 생성 대상이 없다. RECEIPT_REWARDS 및 REWARD_BANK_PAYOUTS는 모두 off였다. 원장 미생성을 백업·복원 완료로 간주하지 않는다. 최초 원장 생성 후 실제 백업과 격리 복원 확인이 남아 있다.

## 2026-10-04 브라우저 검수

로컬 OFF 환경의 격리 디자인 미리보기에서 360x640·390x844 반응형 화면을 확인했다. 가로 넘침 없음, 폼 펼침, 스크롤, 20건·계정당 1건·한국시간 마감 문구, 미리보기 제출 버튼 비활성을 확인했다. 이전 게스트 인증으로 내 포인트 조회가 401이면 인증을 한 번 갱신해 서버가 반환한 본인 UID로 조회한다. 지급 신청 POST를 자동 재시도하지 않음을 테스트했다. 모집 OFF 상태는 영수증·계좌 지급 영역 모두 모집 전 안내를 표시한다.

실기기 QA는 미완료다. 카카오 인앱/iOS Safari/Android Chrome에서 다음 네 흐름을 확인한다.

1. 위치 권한 허용·거절 → 취향 선택 → 방문/배달 및 반경 선택.
2. 추천 → 다른 가게 → 후보 소진 → 다른 메뉴 → 취향 화면 복귀. 사진 잔상·선택 중 멈춤도 확인.
3. 가게 상세 → 닫기 → 선택 완료 → 영수증 폼 펼침. 버튼 잘림·스크롤·키보드·사진 선택 확인. 운영 OFF 상태에서는 실제 제출하지 않는다.
4. 관리자 2FA 로그인 → 목록 조회 및 모집 전 포인트 안내. 실거래 승인·송금은 하지 않는다.

실제 카메라 사진 업로드·승인·포인트 적립은 별도의 비공개 QA 환경에서 검증한 후 오픈한다. 공개 모집을 켜서 테스트를 대신하지 않는다. 발견 사항은 기기·브라우저·화면·재현 순서를 기록한다.
