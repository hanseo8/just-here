# 시드 상권 — 직장 허브 × 행정동

유저: **불특정 다수**. 허브는 공급 단위.  
원칙: 구가 아니라 동(·존). **한 번에 한 허브만 GA.**

---

## 0. W0 확정: 인천 송도

| | |
|--|--|
| **hub_id** | `hub_songdo` |
| **market_id** | `songdo_v1` |
| **권역** | 인천 연수구 송도국제도시 |
| **성격** | 오피스·캠퍼스·컨벤션·주거 혼합 점심권 |
| **런칭** | DAU 1,000 전 **유일한 시드 허브** |

다른 허브(성수·여의도·판교·남동 등)는 **송도 1,000 DAU 이후** 확장 후보.

운영 계층:

```
hub_songdo
  └─ songdo_v1 (beta/ga)
       └─ 송도1~5동 (+ zone)
            └─ places
```

## 2. 송도 제품 기본값

| | 값 |
|--|-----|
| 방문 반경 | 500–700m (스마트) |
| 배달 반경 | 1–1.5km (비·고민감 ≤1km) |
| 기본 travel | walk (단지 넓으면 일부 car 힌트) |
| 예산 힌트 | 1–2만 |

피드 반경은 **유저 실시간 GPS** 기준.  
송도 안 = `hub_full`, 밖 = `national_light` ([EXPERIENCE-TIERS.md](./EXPERIENCE-TIERS.md)).
