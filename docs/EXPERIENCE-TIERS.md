# 경험 티어 (허브 풀 / 전국 라이트)

Status: Implemented in MVP v0.2  
허브 시드 = **인천 송도**. 서비스 이용 = **전국 GPS**.

---

## 모델

| 티어 | 조건 | 재고 | UX |
|------|------|------|-----|
| `hub_full` | 송도 센터 반경 ≈4.5km | 큐레이션 시드 (사진·민감도) | 「오늘 점심은 그냥여기 어때?」 |
| `national_light` | 그 외 전국 | ① 카카오 로컬 음식점 ② 키 없으면 폴백 카드 | 「여기도 그냥여기 — 근처로」 |

공통: 실시간 GPS + 방문/배달 스마트 반경 + 스와이프.

---

## 런칭 메시지

- 마케팅: “전국에서 근처로 고른다”
- 송도: 풀경험(품질·브랜딩 거점, DAU 엔진)
- 송도 밖: 라이트 — 빈 화면보다 실제 상호(카카오) 우선

---

## 환경

```bat
set KAKAO_REST_API_KEY=your_key
```

`.env`에 넣어도 됨.

**키만으로는 부족하다.** 반드시:

1. [developers.kakao.com](https://developers.kakao.com) → **내 애플리케이션** → `그냥여기`
2. 왼쪽 **제품 설정** → **카카오맵**
3. **활성화 설정 = ON**

안 켜면 Local API가 **403** 나고, 앱은 라이트 폴백으로 동작한다.  
(계정당 카카오맵 기본 활성화는 앱 1개가 일반적)

없으면 전국도 폴백 카드로 스와이프는 됨 (데모용). 런칭 전에는 키+맵 활성화 필수.
