# 런칭 · 유저 확보 (DAU 1,000)

Status: CTO 목표 잠금  
**성공 = 서비스 런칭 + 하루 활성 사용자 1,000명.** 완벽함은 목표가 아니다.

---

## 1. 왜 1,000인가

- 제품·채널·재고 루프가 “돌아간다”는 최소 증명
- 그 전에는 기능 욕심보다 **유입 × 첫 성공 경험**에 전부 투입
- 1,000 넘기 전: 연구급 AI / 전국 확장 / 숏폼 금지

---

## 2. 경로 (거칠게)

| Phase | 기간 감 | 목표 | 하는 일 |
|-------|---------|------|---------|
| P0 내부 | ~2주 | 팀이 매일 씀 | 웹/앱 스와이프 → 핸드오프 안정 |
| P1 소프트런칭 | ~4–6주 | DAU 50–100 | **송도** 시드 + 지인·오피스·카톡 |
| P2 오픈 | 이후 | **DAU 1,000** | 영수증 공유·Duo·점심 푸시·가벼운 광고 |

허브는 **인천 송도 한곳부터**. 타 허브 동시 GA 하지 말 것.

---

## 3. 유저 어디서 모으나 (런칭용)

1. **오가닉 공유** — 식탐 영수증, Duo 링크 (제품 안에 심기)
2. **거점** — 오피스/대학 단톡, 점심 고민 채널
3. **콘텐츠** — “오늘 점심 그냥여기” 숏폼 10개면 충분 (앱 완성도보다 노출)
4. **유료** — DAU 200 찍힌 뒤 소액 테스트 (그 전 돈 태우지 말 것)

---

## 4. 출시 컷라인 (이하면 나간다)

- [x] 실시간 위치 → 근처 카드
- [x] 방문/배달 토글 + 딥링크 (지도/배민)
- [x] 취향 3장 + Nope 학습
- [ ] 크래시로 첫 세션이 안 죽는 수준
- [x] 허브 1곳 빈 피드가 점심때 치명적이지 않음 (시드 폴백 강제)
- [x] 공유 1경로 (식탐 영수증 — Web Share / 링크 복사 → `/r/{id}`)
- [x] 실날씨 자동 (Open-Meteo) → 스마트 토글
- [x] Duo 3+3 교집합 1곳 (`/duo/{id}`)

없으면 안 나감. 있으면 **나간다.** 다듬기는 출시 후.

---

## 5. 안 하는 것 (1,000 전)

- GNN / 고도 ML
- 전국·타 허브 동시 완벽 시드 (송도 먼저)
- 숏폼 카드, 혼잡도, 타임세일
- 예쁜 설정·프로필 과투자
