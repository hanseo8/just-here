# 고객 영수증 업로드·관리자 검토 확인

현재 운영 경로는 고객 /my#receipt-upload-entry, 관리자 /static/admin-rewards.html 이다. 기존 접수/비공개 사진/승인·반려/내역 기능을 재사용한다.

## 이번 로컬 보완
- 동일한 파일 입력을 유지하면서 사진 촬영(capture=environment)/앨범 선택 버튼 추가. 촬영만으로 제출하지 않으며 사진 선택 취소 피드백 제공. 지원 기기에 따라 카메라 대신 파일 선택기가 열릴 수 있다.
- 기존 사진 미리보기·8MB JPG/PNG/WEBP 제한·결제시각/금액/승인번호·선택 후기 및 전송 중 표시 유지.
- 관리자 화면 색상 정리, 접수 검토 안내·상태 표시·사진 조회 실패 안내 추가. 검토 중 건만 승인·반려 가능하도록 표시하고 중복 클릭 방지. 반려 사유 필수 유지, 처리 결과가 불명확하면 새로 불러와 확인 안내. 이미지 object URL은 재조회·페이지 종료 시 해제.
- 승인은 포인트 적립이고 계좌 송금과 별개임을 표시.

## 업로드 자격
본인인증만으로 자동 업로드 자격을 부여하지 않는다. 현재 일반 파일럿이 닫혀 있으므로 베타 신청→관리자 선정→선정 후 앱 가게 선택→식사 영수증 접수가 필요하다. 15명·14일·하루 3건·최대 42건·승인 300원, 별도 참여비 기존 조건과 운영 예산은 변경하지 않았다.

## 검증
- check-receipt-settlement-flow: 모의 본인인증→사진 접수→타 계정 사진 차단→중복 거부→부정적 후기 승인→승인 멱등성·최종 상태 충돌→반려·보상 원장 일치. 임시 DB이며 실제 송금 없음.
- check-my-ui, check-receipt-flow-ui, check-receipt-picker 및 구문·diff 검사 통과.
- 로컬 8027 임시 데이터에서 고객 검토 중300P→관리자 사진·후기 조회→승인→고객 사용 가능300P/검토 중0P 및 처리 완료 건의 결정 버튼 제거 확인.
- 인증 없는 관리자 목록·사진 API 401 확인. 운영 고객 접수·선정·승인·반려·지급은 실행하지 않았다.
- output/receipt-upload-review-20261121.jpg, output/receipt-admin-review-20261121.jpg. 모든 화면 데이터는 검증용이며 실제 고객 영수증이 아니다.

이번 보완은 로컬 개발·검증 상태이다. 운영 배포나 APK 빌드, 실제 휴대폰 카메라 촬영 실기기 검수는 이번 작업에 포함하지 않았다.
