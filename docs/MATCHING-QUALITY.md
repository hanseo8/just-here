# 메뉴·가게 사진 매칭 개선 — 3번 로컬 작업

## 수정한 문제

1. 이름 일부와 300m 거리만으로 사진 지점을 연결하던 조건을 강화했다. 도로명·지번 건물번호가 충돌하면 제외한다. 동일 이름은 120m, 이름 일부 일치는 같은 주소와 60m 이내를 요구한다. 서로 다른 지점명·너무 짧은 이름·유효하지 않은 좌표는 보수적으로 처리한다.
2. 사진이 있는 후보를 무조건 앞세우던 선택을 제거했다. 이름 일치도와 거리로 먼저 가게를 고른다. 비슷한 위치의 복수 후보가 모호하면 사진을 붙이지 않는다.
3. 여러 취향의 검색어를 순서대로 잘라 앞쪽 취향만 남던 문제를 수정했다. 최대 6개 한도 안에서 선택한 종류별 검색어를 번갈아 배정한다. 비빔밥·국밥 단독 선택은 해당 음식 검색을 유지한다.
4. 승인된 메뉴 사진으로 교체했는데 이전 Google 출처·작성자 조회가 남을 수 있던 문제를 수정했다. 교체한 이미지에 이전 출처를 표시하지 않는다.

## 검증

- check-matching-quality: 같은 지점/다른 주소/다른 지점/거리 경계/모호한 복수 후보/사진 없는 가까운 가게/선택 종류 검색 배분/메뉴 사진 출처 교체를 가짜 응답으로 검증.
- check-google-photos: 서명 및 사진 리디렉션 시 API 키를 외부 이미지 호스트로 보내지 않는 기존 검사 통과.
- check-photo-state: 이전 카드의 지연 응답, 실패한 사진, 유료 사진 미리 불러오기 방지 검사 통과.
- 기존 방문·배달·혼합 취향·메뉴 필터·조정·빈 결과·확인 메뉴 흐름을 임시 데이터로 검사.

## 범위와 한계

이 기준은 오매칭 감소를 위한 보수적 기준이며 모든 실제 지점의 정확도를 보장하는 측정값은 아니다. 지점 좌표·표기가 다르면 사진이 줄어들 수 있다. 실제 가게 등록 사진도 사용자가 선택한 음식 사진임을 보장하지 않는다. 메뉴 판매를 직접 확인하지 못한 검색 결과는 기존처럼 추정/검색 기반으로 표시한다. 이미지와 메타데이터는 별도 조회이므로 공급자 측 사진 순서 변경에 대한 완전한 동일성 보장은 아직 없다.
Google 사진 제공·작성자 표시 관련 공식 설명: https://developers.google.com/maps/documentation/places/web-service/place-photos

운영에는 2번 위치 기능만 배포했으며 이 3번 변경은 아직 로컬 상태다. 운영 데이터·가격·보상 설정·네이티브 패키지는 변경하지 않았다.
