## Mac 없는 iOS 빌드
`.github/workflows/mobile-build-verify.yml`은 사용자가 직접 실행하는 컴파일 검사 워크플로다. 자동 실행·스토어 업로드·유료 계정 등록은 하지 않는다.
iOS 작업은 GitHub의 macOS 환경에서 서명 없는 시뮬레이터 빌드를 시도한다. 현재 이 워크플로는 실행하지 않았고 성공도 확인하지 않았다.
이 검사가 통과해도 실제 iPhone용 서명·TestFlight·App Store 심사를 대체하지 못한다. 실행 전 계정의 Actions 사용량·결제 정책을 확인한다.
