그냥여기 — 카카오 로그인(도감 저장) 시나리오

서비스: https://www.justthis.co.kr · 용도: 카카오 디벨로퍼스 개인정보 동의항목/로그인 심사 참고

1. 서비스 요약

그냥여기는 근처 식당·메뉴를 스와이프로 고르는 웹앱입니다. 회원가입 창 없이 바로 이용(게스트)하며, 칭호 도감을 영구 저장할 때 선택적으로 카카오 로그인을 사용합니다.

2. 이용·연동 흐름

  1. 이용자가 https://www.justthis.co.kr 접속
  2. 위치·취향 선택 후 스와이프로 메뉴 매칭 (회원가입 없음)
  3. 매칭 완료 화면에서 「카카오로 도감 저장」 버튼 노출
  4. 버튼 탭 → 카카오 로그인 동의 화면
  5. 동의 항목: 닉네임 (선택/필수 범위는 콘솔 설정에 따름)
  6. 로그인 완료 후 게스트에 쌓인 취향·칭호를 카카오 계정에 연결

3. 화면 예시 (완료 화면 CTA)

완료 화면 하단 버튼 예시
카카오로 도감 저장

수집 목적 문구(앱 내): 칭호 도감·취향을 계정에 안전하게 저장합니다.

4. 수집 항목

카카오: 회원번호, 닉네임
서비스: 스와이프/취향/칭호, (동의 시) 위치
이메일·전화번호 미수집
